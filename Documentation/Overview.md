# Windows Server Administration

## Overview

This repository contains documentation on Windows Server administration, covering the core services, roles, and management tasks required to maintain Windows Server environments in enterprise organizations.

The documentation is designed to demonstrate practical knowledge of Windows Server administration, Active Directory management, networking services, remote administration, PowerShell, and troubleshooting.

---

## Topics Covered

- Windows Server Overview
- Active Directory Domain Services (AD DS)
- Domain Name System (DNS)
- Dynamic Host Configuration Protocol (DHCP)
- Group Policy (GPO)
- File Server Management
- Remote Desktop Services (RDS)
- Microsoft Entra Connect
- Windows PowerShell
- Windows Server Troubleshooting
